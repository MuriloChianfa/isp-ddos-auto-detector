# SBRC 2026 Slides

Beamer presentation for the paper.

## Requirements

On Debian/Ubuntu, a minimal install is usually enough:

```bash
sudo apt install texlive-latex-recommended texlive-latex-extra texlive-fonts-recommended
```

## Build

From this directory:

```bash
cd slides
pdflatex main.tex
pdflatex main.tex
```

The output is written to `main.pdf`.
